# Intoday

A research workspace for long-term thinking.

Intoday helps researchers collect sources, organize context, and preserve the connections between ideas over time.

[Visit intoday.cc](https://www.intoday.cc/)

## About

This repository contains the Intoday landing page. The site uses a quiet editorial design to introduce the Collect, Organize, and Connect workflow through real product screenshots and focused product copy.

## Highlights

- Responsive across desktop, tablet, and mobile
- Available in English, Chinese, Japanese, Thai, and Malay
- Subtle motion with reduced-motion support
- Expandable product screenshots and FAQ items
- Privacy Policy and Terms of Service pages

## Run locally

The site is built with plain HTML, CSS, and JavaScript. No installation or build step is required.

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.
